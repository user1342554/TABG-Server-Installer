# Multiplayer Shooting Range

Multiplayer TABG WilhelmTest shooting range.

- Fixed shooting-range spawn.
- Infinite respawns.
- Starter gun and ammunition after each respawn.
- F6 searchable item browser through the paired client mod.
- Up to 20 players; the pre-match lobby waits for two players, and late joiners remain accepted afterward.

Every joining player needs `TabgInstaller.RangeMap.Client.dll`. The dedicated
server needs `TabgInstaller.RangeMap.Server.dll`. Remove the DevTestMap pair
before activating this preset and keep AntiCheatBypass disabled.

The saved password is blank by design. Set it only in the live server copy.
