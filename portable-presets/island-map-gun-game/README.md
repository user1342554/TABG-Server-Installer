# Island Map Gun Game

Multiplayer Gun Game on TABG's hidden map we call Island Map.

- Native weapon progression, with victory at 32 kills.
- Enemy shots replicate to every compatible player, including their projectiles and tracers.
- Infinite respawns at the three verified Island Map positions.
- One second of server-authoritative spawn protection.
- Server-authoritative water damage.
- F6 item browser through the paired client mod.
- Up to 20 players; the match begins when two players have joined.

Every joining player needs `TabgInstaller.DevTestMap.Client.dll`. The dedicated
server needs `TabgInstaller.DevTestMap.Server.dll`. Remove the RangeMap pair
before activating this preset and keep AntiCheatBypass disabled.

The saved password is blank by design. Set it only in the live server copy.
